# Skill 2.0.0 安装包

[下载 aibt-workshop.zip](aibt-workshop.zip?raw=true)，按 [安装指引](../docs/INSTALL.md) 使用。

同一份包适用于 WorkBuddy 导入及 Qoder 项目安装，包含一层 aibt-workshop/，内有 SKILL.md、scripts/workshop.mjs、scripts/course.mjs 与 references/transports.md。不含账号凭证，课程登记从老师 main 读取。

更新前核对现有版本，不直接覆盖。老师可提前通过课程群组或 U 盘分发；下载校验见 [SHA256SUMS.txt](SHA256SUMS.txt)。维护者用 `python3 tools/package-skill.py` 重新生成包及校验值。
