# 課程完整 Prompt 清單

除安裝之外，以下都使用同一個 `aibt-workshop` Skill。把 `〈……〉` 換成自己的資料。已明確選取資料夾時，可直接說「這個資料夾」。

## 第一次上課

| 目的 | 可以直接複製的 Prompt |
|---|---|
| 安裝 | 請依 https://github.com/f3484134/AIBT-WORKSHOP-261107/blob/main/docs/INSTALL.md，在目前課程專案安裝 aibt-workshop。完成後引導我初始化並測試。 |
| 一次完成初始化與測試 | 使用 aibt-workshop，幫我初始化課程並完成首次連線測試。請確認我的登入帳號、建立或確認 Fork，上傳測試文字與圖片，建立草稿 PR 並讀回驗證，給我每一步結果和 PR 連結。 |
| 只診斷，不上傳 | 使用 aibt-workshop，檢查目前 GitHub 登入、課程讀取和可用工具。只做唯讀診斷，列出尚未測試的寫入能力。 |
| 已手動 Fork | 我已經 Fork AIBT-WORKSHOP-261107，請使用 aibt-workshop 確認這是正確的 Fork，接著完成首次連線測試。 |
| 再測一次 | 使用 aibt-workshop，重新執行完整連線測試。先找既有的測試 PR，避免重複建立。 |
| Connector 能力不足 | 使用 aibt-workshop 的 CLI 備援。先檢查並只安裝缺少的官方工具，引導我用瀏覽器登入自己的 GitHub，然後重做完整測試。 |
| 老師本機試跑 | 使用 aibt-workshop。我是老師 f3484134，請使用老師測試模式，實際上傳測試文字與圖片並建立草稿 PR；請標示學生 Fork 仍未驗證。 |

## 每堂課交件

| 目的 | 可以直接複製的 Prompt |
|---|---|
| 提交指定資料夾 | 提交第 2 課作業，作品在這個資料夾：〈路徑〉。 |
| 提交目前選取資料夾 | 使用 aibt-workshop，提交第 1 課作業，作品就是目前選取的資料夾。 |
| 補作品說明 | 使用 aibt-workshop，替這個作品資料夾整理 README，說明作品用途、使用方法、我的做法與學到的事。先在本地整理，尚不提交。 |
| 預覽交件內容 | 使用 aibt-workshop，預覽這個資料夾若作為第 2 課作業，會上傳哪些檔案、略過哪些檔案。只預覽，不寫入 GitHub。 |
| 含圖片／PDF／簡報 | 使用 aibt-workshop，提交第 3 課作業，資料夾是〈路徑〉，其中有圖片、PDF 或簡報。請保留原始格式，並驗證這些檔案也上傳成功。 |
| 附上公開展示連結 | 使用 aibt-workshop，將這個公開作品連結〈URL〉寫進作品 README，再將〈資料夾〉提交為第 2 課作業。 |
| 改進後重交 | 更新第 2 課作業，作品在〈路徑〉。請使用 aibt-workshop 更新原本仍開啟的 PR，不重複開提交單。 |
| 上次已合併後補交 | 使用 aibt-workshop，我的第 2 課作業已合併，現在要補交〈資料夾〉的新版本，請建立新的提交 PR。 |
| 查是否交成功 | 使用 aibt-workshop，查詢我第 2 課作業的作品連結、PR 連結，以及是否等待合併、已合併或已關閉。 |
| 列出自己的提交 | 使用 aibt-workshop，列出我的課堂提交與測試 PR，附狀態和連結，只查詢。 |

## 故障與重試

| 目的 | 可以直接複製的 Prompt |
|---|---|
| 網路中斷後接續 | 剛才提交第 2 課時網路中斷。請使用 aibt-workshop 先查遠端是否已成功上傳或建立 PR，再接續提交〈資料夾〉，不要重複開 PR。 |
| 換了 IDE | 使用 aibt-workshop，我換了 IDE。請重新確認這個工具的登入帳號、自己的 Fork 和連線，不要假設另一個 IDE 的授權能共用。 |
| 誤用別人帳號 | 使用 aibt-workshop，先停止上傳，告訴我目前實際登入帳號，並引導我在瀏覽器改成自己的 GitHub 帳號。完成後重新測試。 |
| 同名 repo 衝突 | 使用 aibt-workshop，檢查我的同名 repo 是否為本課程的 Fork。若不是，請說明狀況，不要刪除或覆寫它。 |
| 不知道失敗在哪 | 使用 aibt-workshop，幫我診斷最近一次提交失敗的位置，列出登入、課程讀取、Fork、檔案上傳、PR 哪些通過，給我最短的下一步。不要輸出密碼或 Token。 |

## 觀摩與學習

| 目的 | 可以直接複製的 Prompt |
|---|---|
| 看同學作品 | 使用 aibt-workshop，幫我找班上第 2 課的公開作品，包括尚未合併的 PR，列出可點的連結。 |
| 比較做法 | 使用 aibt-workshop，比較這兩份作品〈連結 A〉、〈連結 B〉的做法與可學習之處，只讀取，不修改或發評論。 |
| 改進自己的作品 | 參考這份公開作品〈連結〉，幫我分析自己的〈資料夾〉可以怎麼改進。請註明借鑑來源，先修改本地作品，尚不提交。 |

「第 2 課」只是範例，請換成老師當堂指定的課次。正式交件要收到 PR 連結才完成；老師合併後才會出現在課程 main。只給檔案上傳連結、Fork 連結或「已連接」仍不足以代表整條流程成功。
