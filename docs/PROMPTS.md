# 课程完整 Prompt 清单

初始化、连接测试和提交等操作使用同一个 `aibt-workshop` Skill；读取公开练习材料也可由 IDE 自带的 GitHub 或网页工具完成。把 `〈……〉` 换成自己的资料。已明确选取文件夹时，可直接说「这个文件夹」。

## 第一次上课

| 目的 | 可以直接复制的 Prompt |
|---|---|
| 安装 | 请依 https://github.com/f3484134/AIBT-WORKSHOP-261107/blob/main/docs/INSTALL.md，在当前课程项目安装 aibt-workshop。完成后引导我初始化并测试。 |
| 一次完成初始化与测试 | 使用 aibt-workshop，帮我初始化课程并完成首次连接测试。请确认我的登录账号、创建或确认 Fork，上传测试文字与图片，创建草稿 PR 并读取验证，给我每一步结果和 PR 链接。 |
| 只诊断，不上传 | 使用 aibt-workshop，检查当前 GitHub 登录、课程读取和可用工具。只做读取诊断，列出尚未测试的写入能力。 |
| 已手动 Fork | 我已经 Fork AIBT-WORKSHOP-261107，请使用 aibt-workshop 确认这是正确的 Fork，接着完成首次连接测试。 |
| 再测一次 | 使用 aibt-workshop，重新执行完整连接测试。先找已有的测试 PR，避免重复创建。 |
| Connector 能力不足 | 使用 aibt-workshop 的 CLI 备用方案。先检查并只安装缺少的官方工具，引导我用浏览器登录自己的 GitHub，然后重做完整测试。 |
| 老师本机试跑 | 使用 aibt-workshop。我是老师 f3484134，请使用老师测试模式，实际上传测试文字与图片并创建草稿 PR；请标明学生 Fork 仍未验证。 |

## 准备练习三材料

[练习三材料页](../lessons/lesson-03/README.md) 提供 Word 原文件与 Markdown 文字版。可以直接复制：

```text
帮我准备练习三的材料。请读取老师课程仓库的 main 分支：
https://github.com/f3484134/AIBT-WORKSHOP-261107/blob/main/lessons/lesson-03/README.md
按照其中的材料链接，把访谈笔记的 Word 原文件和 Markdown 文字版保存到当前项目的 materials 文件夹。
确认 Word 文件可以正常读取、文字版包含 5 位受访者的完整笔记，告诉我保存位置，然后等待老师的课堂要求。
```

完成分析后提交：

```text
使用 aibt-workshop，提交第 3 课作业（练习三），作品在这个文件夹：〈作品文件夹路径〉。
```

## 每堂课提交

| 目的 | 可以直接复制的 Prompt |
|---|---|
| 提交指定文件夹 | 提交第 2 课作业，作品在这个文件夹：〈路径〉。 |
| 提交当前选取文件夹 | 使用 aibt-workshop，提交第 1 课作业，作品就是当前选取的文件夹。 |
| 补作品说明 | 使用 aibt-workshop，替这个作品文件夹整理 README，说明作品用途、使用方法、我的做法与学到的事。先在本地整理，尚不提交。 |
| 预览提交内容 | 使用 aibt-workshop，预览这个文件夹若作为第 2 课作业，会上传哪些文件、略过哪些文件。只预览，不写入 GitHub。 |
| 含图片／PDF／演示文稿 | 使用 aibt-workshop，提交第 3 课作业，文件夹是〈路径〉，其中有图片、PDF 或演示文稿。请保留原始格式，并验证这些文件也上传成功。 |
| 附上公开展示链接 | 使用 aibt-workshop，将这个公开作品链接〈URL〉写进作品 README，再将〈文件夹〉提交为第 2 课作业。 |
| 改进后重交 | 更新第 2 课作业，作品在〈路径〉。请使用 aibt-workshop 更新原本仍打开的 PR，不重复开提交单。 |
| 上次已合并后补交 | 使用 aibt-workshop，我的第 2 课作业已合并，现在要补交〈文件夹〉的新版本，请创建新的提交 PR。 |
| 查是否交成功 | 使用 aibt-workshop，查询我第 2 课作业的作品链接、PR 链接，以及是否等待合并、已合并或已关闭。 |
| 列出自己的提交 | 使用 aibt-workshop，列出我的课堂提交与测试 PR，附状态和链接，只查询。 |

## 故障与重试

| 目的 | 可以直接复制的 Prompt |
|---|---|
| 网络中断后接续 | 刚才提交第 2 课时网络中断。请使用 aibt-workshop 先查远端是否已成功上传或创建 PR，再接续提交〈文件夹〉，不要重复开 PR。 |
| 换了 IDE | 使用 aibt-workshop，我换了 IDE。请重新确认这个工具的登录账号、自己的 Fork 和连接，不要假设另一个 IDE 的授权能共用。 |
| 误用别人账号 | 使用 aibt-workshop，先停止上传，告诉我当前实际登录账号，并引导我在浏览器改成自己的 GitHub 账号。完成后重新测试。 |
| 同名 repo 冲突 | 使用 aibt-workshop，检查我的同名 repo 是否为本课程的 Fork。若不是，请说明状况，不要删除或覆盖它。 |
| 不知道失败在哪 | 使用 aibt-workshop，帮我诊断最近一次提交失败的位置，列出登录、课程读取、Fork、文件上传、PR 哪些通过，给我最短的下一步。不要输出密码或 Token。 |

## 观摩与学习

| 目的 | 可以直接复制的 Prompt |
|---|---|
| 看同学作品 | 使用 aibt-workshop，帮我找班上第 2 课的公开作品，包括尚未合并的 PR，列出可点的链接。 |
| 比较做法 | 使用 aibt-workshop，比较这两份作品〈链接 A〉、〈链接 B〉的做法与可学习之处，只读取，不修改或发评论。 |
| 改进自己的作品 | 参考这份公开作品〈链接〉，帮我分析自己的〈文件夹〉可以怎么改进。请注明借鉴来源，先修改本地作品，尚不提交。 |

「第 2 课」只是示例，请换成老师当堂指定的课次。正式提交要收到 PR 链接才完成；老师合并后才会出现在课程 main。只给文件上传链接、Fork 链接或「已连接」仍不足以代表整条流程成功。
