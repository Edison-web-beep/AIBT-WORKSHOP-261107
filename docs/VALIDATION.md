维护分支已通过 Node.js 20 与当前 Node.js 的完整 `node --test`。测试涵盖：

- 练习/组号归一、可信老师登记、未登记/非代表账号拒绝。
- 练习与组别目录、不同组独立分支、二进制保真、重复提交复用、关闭后新版本、并发与错误哈希停止。
- PR 作者、来源仓库、base/head、标题、范围、跨组重命名、删除、README、链接、文件大小及完整目录检查。
