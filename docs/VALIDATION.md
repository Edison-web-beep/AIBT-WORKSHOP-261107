最终混合版 Skill 已通过九项独立文档情景验证：个人/小组目录和分支、成员并行、小组代表排他、跨组授权、缺类型补问、WorkBuddy 二进制能力、空名单时连接测试，以及已选定 CLI 账号等均符合规则。

维护审查补充回归：排除维护 PR 的统计/复用，课程测试只运行根 tests/；覆盖同组多人并行、个人/小组互不覆盖以及一个账号跨组授权。双代表真正同时创建 PR 时，较晚的本次新建重复单关闭，只保留一单，不能双双报告成功；已存在的 PR 不自动关闭，不同成员个人并行仍通过。
