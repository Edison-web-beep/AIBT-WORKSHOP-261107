# 小组作品

作品按 **练习 → 组别** 排列，例如 `lesson-01/group-03/README.md`。由老师在 [course.json](../course.json) 登记的各组代表通过 Skill 提交，老师合并后归档到这里。

[查看提交规则](../docs/SUBMISSION-RULES.md) · [查看待审 PR](https://github.com/f3484134/AIBT-WORKSHOP-261107/pulls) · [课堂作品总览](https://github.com/f3484134/AIBT-WORKSHOP-261107/actions/workflows/submission-overview.yml)

总览位于最新成功运行的 Summary，按练习、组别显示待登记、未交、草稿、待审和已合并；尚未合并的作品可直接从 PR 观摩。

请保留他人作品来源与授权信息。公开可阅读不等于可任意再发布。旧版个人目录不会自动迁移或删除。
