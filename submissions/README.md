# 课堂作品

作品按 **练习 → 组别 → 个人/小组** 归档：

- `lesson-NN/group-NN/individual/<账号>/`：成员各自的个人作品，可并行提交。
- `lesson-NN/group-NN/team/`：由学生代表提交的小组共同作品。

组号由学生自报，账号来自实际登录；同一账号可参与或代表多个组，也可同时提交两类作品。无需老师预建名单或组别目录，老师在 PR 中确认。

[提交规则](../docs/SUBMISSION-RULES.md) · [待审 PR](https://github.com/f3484134/AIBT-WORKSHOP-261107/pulls) · [课堂作品总览](https://github.com/f3484134/AIBT-WORKSHOP-261107/actions/workflows/submission-overview.yml)

总览位于最新成功运行的 Summary，按练习、组别、类型和账号显示状态、作品和提交单。个人与小组作业分别统计；未合并作品可从 PR 观摩。没有完整名单时无法推断全班谁还没交。

保留他人作品来源与授权，公开阅读不等于任意再发布。旧版个人目录不自动迁移或删除。
