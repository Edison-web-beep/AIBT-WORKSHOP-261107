# AIBT WORKSHOP · 261107

课程教材、小组作品与课堂提交 Skill。老师：[@f3484134](https://github.com/f3484134)。

**学生：[三步开始](docs/STUDENT-START.md) → [安装 Skill](docs/INSTALL.md) → [提交规则](docs/SUBMISSION-RULES.md)。**

1. 注册自己的 GitHub 个人账号，安装 aibt-workshop **2.0.0**（Qoder 项目安装或 WorkBuddy 导入 ZIP）。
2. 说「使用 aibt-workshop，帮我初始化课程并完成首次连接测试」。
3. 每组由登记代表提交，例如：**「提交练习一第三组，作品在当前选中的文件夹。」**

课程有 **4 个练习**。作品按 `submissions/lesson-NN/group-NN/` 自动归档；各组提交代表由老师在 [course.json](course.json) 登记。当前先列出 5 个待登记组别，可继续增加；null 表示尚未登记，不能正式交作业，仍可进行连接测试。

老师合并 PR 后，作品出现在 [submissions](submissions/)。合并前可在 [PR 清单](https://github.com/f3484134/AIBT-WORKSHOP-261107/pulls) 查看。

**[查看课堂作品总览](https://github.com/f3484134/AIBT-WORKSHOP-261107/actions/workflows/submission-overview.yml)**：打开最新成功运行的 Summary，按练习和组别查看待登记、未交、草稿、待审和已合并状态。工作流随本次更新合并后启用，也可手动刷新。

仓库、Fork、PR 和历史均公开。只提交可公开作品，不放密码、API Key、个人或公司内部资料。使用 GitHub 账号，不要求真名、手机或邮箱；转用他人作品先确认来源与授权。
