# 练习三 访谈笔记分析

本练习使用老师提供的 5 位受访者的访谈笔记。请先取得材料，再按照老师的课堂要求开展分析。

## 练习材料

- [下载 Word 原文件](materials/访谈笔记分析练习.docx?raw=true)：与老师提供的原文件内容一致，文件名使用简体中文。
- [在线阅读 Markdown 文字版](materials/访谈笔记分析练习.md)：方便 Agent 直接读取，保留原文与段落顺序。

## 让 Agent 准备材料

把下面的 Prompt 复制到能读取 GitHub 或网页、保存本地文件的 Agent IDE：

```text
帮我准备练习三的材料。请读取老师课程仓库的 main 分支：
https://github.com/f3484134/AIBT-WORKSHOP-261107/blob/main/lessons/lesson-03/README.md
按照其中的材料链接，把访谈笔记的 Word 原文件和 Markdown 文字版保存到当前项目的 materials 文件夹。
确认 Word 文件可以正常读取、文字版包含 5 位受访者的完整笔记，告诉我保存位置，然后等待老师的课堂要求。
```

如果 IDE 无法自动下载，可以点击上方「下载 Word 原文件」，把文件拖入自己的项目，再让 Agent 读取。已经 Fork 的同学也可直接使用老师仓库的材料链接，取得本次新增的材料。

## 提交练习结果

按照老师的课堂要求完成分析后，将要分享的分析结果和作品说明放在一个独立文件夹。本练习的提交目录编号为 `lesson-03`。

```text
使用 aibt-workshop，提交练习三第〈组号〉组的个人作品，作品在当前选中的文件夹。
```

提交成功后，保留 Agent 返回的 PR 链接。更多操作见 [完整 Prompt 清单](../../docs/PROMPTS.md)。
