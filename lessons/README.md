# 课程教材

本课程有四个练习，对应 lesson-01 至 lesson-04，名称及开放练习以根目录 [course.json](../course.json) 为准。老师按课堂安排补充教材。

- [准备与连接测试](lesson-00-setup/README.md)
- [练习三：访谈笔记分析与材料](lesson-03/README.md)
- [教材格式范本](lesson-template/README.md)

学生作品在 `submissions/lesson-NN/group-NN/` 下分别归入 individual/<账号>/（个人）和 team/（小组共同作品），学生自行填写组别及个人/小组类型，使用实际登录账号由 Skill 自动提交，无需老师预建名单。
