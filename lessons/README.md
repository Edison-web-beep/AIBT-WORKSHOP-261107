- [准备与连接测试](lesson-00-setup/README.md)
- [练习三：访谈笔记分析与材料](lesson-03/README.md)
- [教材格式范本](lesson-template/README.md)

学生作品在 `submissions/lesson-NN/group-NN/` 下分别归入 individual/<账号>/（个人）和 team/（小组共同作品），由老师登记的对应角色使用 Skill 自动提交。
